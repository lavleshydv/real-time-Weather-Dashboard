# Real-Time Weather Dashboard

A beautiful, glassmorphism-styled Weather Dashboard built with Vanilla HTML, CSS, and asynchronous JavaScript.

## Features
- Real-time weather data fetching using the Open-Meteo REST API.
- Modern UI with glassmorphism effects.
- Graceful error handling for invalid cities and network issues.

## How to Run
Simply open `index.html` in your web browser. No local server required!
